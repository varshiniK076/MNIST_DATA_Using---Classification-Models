# MNIST Digit Classification
Comprehensive MNIST digit classification project using Classification machine learning models. Features performance comparison, AUC-ROC visualization, and SVM hyperparameter tuning with GridSearchCV to identify the best model. Ideal for exploring model performance, learning ensemble methods, and experimenting with hyperparameter optimization.


This project trains **10 different machine learning models** on the MNIST dataset and compares them using **AUC-ROC curves**, accuracy, and classification reports.
Additionally, an **SVM model is tuned using GridSearchCV** for best performance.

## 🔥 Models Included

* KNN
* Naive Bayes
* Logistic Regression
* Decision Tree
* Random Forest
* AdaBoost
* Gradient Boosting
* XGBoost
* SVM
* Tuned SVM (Best Model)

## 📊 Features

* Train/test performance metrics
* AUC-ROC plots for all models
* GridSearch hyperparameter tuning

## 📈 Output

* AUC-ROC Plot
* Best model parameters
* Best accuracy
